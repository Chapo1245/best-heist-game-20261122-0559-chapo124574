Moonlit Vault — a 3-heist stealth game: 3 heists, 9 guards, 27 treasures, 3 gadgets. Cross the room unseen, dodge vision cones and sweeping cameras, steal every target, and reach the exit before the alarm hits 100. A second campaign, Duskline Casino, ships in the same game (press 2 on the title screen). Every gadget costs kit — a coin toss that pulls a guard away cannot also buy a smoke veil later. Built for make.fun's "Make the best heist game" bounty.

## Run it

```sh
python3 -m http.server 8080 --directory game
# open http://localhost:8080
```

Play with keyboard and mouse: WASD / arrows move, Shift sneak, E grab loot (hold), 1 toss a coin, 2 smoke veil, 3 jam cameras, click to toss a coin at that spot, M mute. No build step, no network — every file the game loads lives under `game/`.
